# V2 Decorator Refactor Plan

## Overview

Refactoring `decoratoPatronus` from Observable-specific tracing to a generic value tracer. The goal is to decorate _anything_ and trace structural paths through function calls, arguments, and returns. Observable-specific logic moves to queries, not the proxy layer.

## Path Structure

```
{FunctionPath}/{call_index}/{arg_index}.{nested_prop}/$
```

### Examples

```
Observable/constructor/0/0                    <- first arg to constructor
Observable/constructor/0/0.delay              <- that arg's delay property
Observable/constructor/0/$                    <- instance (constructor return)
Observable/constructor/0/$/pipe/0/0           <- first arg to pipe call
Observable/constructor/0/$/pipe/0/$           <- pipe return (another observable)
Observable/constructor/0/$/subscribe/0/$      <- subscribe return (subscription)
Observable/of/0/0                             <- first arg to static method
Observable/of/0/$                             <- static method return
```

### Path Semantics

- `/constructor/` - explicit segment for class instantiation
- `/$` - return value of a call (the "output")
- `/0`, `/1` - positional args (no `/args/` prefix)
- `.property` - lodash-style nested access inside args
- `#` - reserved (not used currently)

## Store Structure

```typescript
type Store = {
  fun: Record<string, Fun>
  call: Record<string, Call>
  arg: Record<string, Arg>
}

type Fun = { 
  id: string
  name: string
  ref?: WeakRef<Function>
  call_ids: string[]        // secondary index
}

type Call = { 
  id: string
  fun_id: string
  parent_call_id?: string   // runtime call tree
  arg_ids: string[]         // secondary index
  return_id?: string        // undefined until returns
}

type Arg = { 
  id: string
  call_id: string
  value?: primitive         // inline for primitives
  ref?: WeakRef<object>     // for instances (Observable, etc)
  fun_id?: string           // if value is function
}
```

## Proxy Architecture

### Three-layer approach:

1. **Class proxy** (`construct` trap) → returns instance proxy with path `{path}/constructor/{n}/$`
2. **Instance proxy** (`get` trap) → returns wrapped methods with correct path prefix
3. **Method proxy** (`apply` trap) → records call, wraps args, records return

### Instance Path Propagation

When `new Observable(fn)` returns, the instance proxy carries path `Observable/constructor/0/$`. Future method calls extend this:
- `obs.pipe(...)` → `Observable/constructor/0/$/pipe/0`
- Return → `Observable/constructor/0/$/pipe/0/$`

## Virtual Module Approach

Replace source patching with virtual module wrapping:

```typescript
// Vite plugin
resolveId(source) {
  if (source === 'rxjs') return '\0rxjs'
  if (source.startsWith('rxjs/')) return '\0rxjs:' + source.slice(5)
}

load(id) {
  if (id === '\0rxjs') {
    return generateRxjsWrapper()
  }
  // ... subpath handling
}

function generateRxjsWrapper() {
  return `
    import * as _orig from 'rxjs';
    import { decoratoPatronus } from '@hafley/rxjs-debugger';
    
    export const Observable = decoratoPatronus(_orig.Observable, 'rxjs/Observable');
    export const Subject = decoratoPatronus(_orig.Subject, 'rxjs/Subject');
    // ... all exports
    
    export default _orig;
  `
}
```

### Why Virtual Modules

| Patching Source | Virtual Module |
|-----------------|----------------|
| Modifies node_modules | node_modules untouched |
| Breaks sourcemaps | Sourcemaps work |
| Hard to debug | Clear wrapper boundary |
| Can't undo per-file | Can exclude specific imports |

## Arg Traversal Rules

1. **Primitives** (number, string, boolean, null, undefined) → store `value` inline
2. **Functions** → decorate and store `fun_id` reference
3. **Plain objects/arrays** → traverse recursively, create nested arg entities
4. **Instances** (non-POJO) → stop traversal, store `WeakRef` only

Detection: `lodash.isPlainObject` / `Array.isArray` for traversal, everything else is instance.

## Open Questions for Implementation

2. **Query layer**: How to efficiently query "all observables" or "all subscriptions" from flat arg store?
3. **Memory**: Accepting WeakRef storage for trace chains when functions return functions
