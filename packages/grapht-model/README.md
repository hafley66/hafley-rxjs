# grapht-model

Framework-free contracts for graph source revisions, rendered SVG artifacts,
measured geometry, board placements, sequence focus, and reconciliation.

`@hafley66/grapht` owns the benchmark process protocol. Source-language
packages such as `@hafley66/mmd` and `@hafley66/d2` produce artifacts that
conform to this package. Browser packages supply SVG measurement and board
projection.

The serialized schema version is `grapht-model/0`.
