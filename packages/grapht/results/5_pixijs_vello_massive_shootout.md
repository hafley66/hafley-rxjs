# PixiJS versus Vello Chromium massive-graph shootout

Date: 2026-08-11

## Result

PixiJS WebGL with `ParticleContainer` nodes and one batched edge mesh wins the
validated browser comparison.

At an 800 by 600 backing resolution with DPR 1, PixiJS rendered and completed
the shared scenario sequence through 100,000 nodes. Both PixiJS representations
failed the 120-second visual-validity gate at 250,000 nodes.

Vello's initially recorded 1,000 through 75,000-node results used a 300 by 150
canvas backing buffer displayed at 1024 by 768 through CSS. Those observations
measure the same graph and scenario inputs but less raster work. A corrected
800 by 600 Vello backing buffer saturated the machine before the normalized
matrix completed and produced no valid comparison receipt. The correction was
reverted after the run.

## Controlled inputs

Both adapters received:

- Fixtures generated by `scripts/0_generate_renderer_fixture.mjs`
- The `grapht-render-fixture/0` JSON shape
- The canonical `BENCH_SCENARIO_CASES` sequence
- One Playwright worker
- Headless Chromium
- DPR 1
- Pixel-based visual-validity gating before screenshots and scenarios
- A 120-second visual-validity limit
- An external process timeout to recover from a blocked renderer thread

The PixiJS run used an 800 by 600 renderer backing surface. The Vello receipts
listed below retain the original 300 by 150 backing surface and are excluded
from the winner decision.

## Failure boundary

PixiJS retained and particle tests both reached 100,000 nodes and both failed
at 250,000 nodes before visual validity. The particle result indicates that the
remaining shared edge-mesh construction or upload path dominates beyond
100,000 nodes; replacing retained node objects alone did not move the 250,000
node boundary.

Vello's normalized 800 by 600 experiment caused system saturation before a
valid receipt was written. No normalized Vello breakpoint is claimed.

## Commands

```bash
for size in 1000 5000 10000 25000 50000 100000 250000 500000 1000000; do
  node packages/grapht/scripts/0_generate_renderer_fixture.mjs "$size"
done

GRAPHT_MASSIVE=1 \
GRAPHT_MASSIVE_SIZES=1000,5000,10000,25000,50000,100000 \
gtimeout 600 pnpm --dir packages/grapht/adapters/6_render_pixijs \
  exec playwright test -c playwright.config.ts e2e/2_massive.spec.ts --workers=1
```

Massive specs are excluded from normal Playwright runs. They require
`GRAPHT_MASSIVE=1`; sizes are selected with `GRAPHT_MASSIVE_SIZES`.
