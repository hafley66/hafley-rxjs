## Top 5 risks ranked

1. Incorrect concurrent ownership: the shared getCurrentTest variable can route page operations, soft failures, cancellation, and logs to another test; file scope additionally shares mutable browser state.
2. Untracked async assertions and incomplete poll takeover: tests can finish before assertions settle, while marked poll matchers receive null and ignore the poll budget.
3. Fixture scope and release failures: illegal file dependencies block collection; teardown assertions can prevent context closure and omit failure artifacts.
4. Serve/configuration transport: the command branch never runs, function-valued options lack a worker API, and project-global environment state can mix configurations.
5. Matcher compatibility gaps: omitted protocol arguments, URL overloads, toPass polarity, and snapshot policies change assertions while the matcher-count milestones conceal incomplete coverage.
