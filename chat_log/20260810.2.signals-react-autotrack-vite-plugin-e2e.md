## Problem/Context
- User demanded real e2e, not "I reasoned through it." The plugin transform
  timing was wrong (`enforce: "pre"` ran BEFORE esbuild emitted the
  react/jsx-runtime import, so the regex matched nothing). Fixed to `"post"`.
- Dual-package hazard: e2e first imported `Signal` from `./2_Signal.js` (src
  signalDispatch) while the jsx path used dist signalDispatch -> collector and
  reads on different instances -> no tracking. Fix: import Signal from the
  PACKAGE so one signalDispatch instance.
- React 19 jsx signatures: `jsx/jsxs(type, props, key?)`, `jsxDEV(type, props,
  key, isStatic, source, self)`. Runtime forwards via rest + ElementType cast.

## Solution/Approach
- `track(type)` (4_jsxAuto.ts): WeakMap-cached SignalReact wrap of function
  components; passthrough for intrinsics/Fragment.
- jsx-runtime.ts / jsx-dev-runtime.ts: re-export react/jsx-runtime(-dev) but
  route the type through track.
- vite-plugin.ts signalsJsx(): enforce:"post" transform that rewrites
  `react/jsx-runtime` and `react/jsx-dev-runtime` import specifiers to the
  signals runtime. Works for esbuild (vitest) and @vitejs/plugin-react.
- SignalReact: `activeCollector` (module-level) set during Component(props);
  global signalDispatch get-event subscription routes reads to it; collected
  accessors (signal node `.$`) subscribed via `merge(...accessors.map(skip(1)))`
  in useEffect after commit; cleanup each render; skip(1) avoids the
  BehaviorSubject-current-value subscribe loop.

## Key Insights
- "tested" without e2e is a lie for a build-time transform; the plugin's
  enforce timing (pre vs post) only surfaces when you run a real compile.
- Module duplication (src vs dist instances of a module-level singleton like
  signalDispatch) silently breaks cross-cutting subscriptions; import the
  package, not relative src, in tests that exercise the package surface.
- BehaviorSubject emits current value on subscribe -> useReducer-force loops
  forever; skip(1) per accessor stops it.
- Per-render re-subscribe (useEffect, no deps array) gives correct dep
  re-derivation; cleanup of the prior render unsubscribes stale deps.
- vite automatic-runtime JSX compiles to react/jsx-runtime(-dev) imports; the
  import is emitted by the compiler, so a redirect transform must run post.
- Comment-prod hook max 2 consecutive comment lines; prose-prod bans
  honest/grounded/distill/ruling + deictic filler.
