## Solution/Approach
Bash script: packages/gothic/scripts/0_scaffold.sh, invoked by `pnpm scaffold`, `just scaffold`, or `bash scripts/0_scaffold.sh`.

Commands:
- `page ID`: a pure circle Algo, a SignalReact page, and explicit route registration.
- `section PAGE ID`: new Algo appended to the named notebook.
- `use PAGE ID MODULE:EXPORT`: existing typed Algo as a separately named section.
- `copy SOURCE ID`: independent copy of a scaffolded Algo.
- `input ALGO KEY KIND`: fixed range/number/seed/select/bool/text field template.
- `input --print KEY KIND`: print a snippet for a handwritten spec.
- `--dry-run`: print the exact source diff without writing source files.

Templates are plain text .tpl files in scripts/templates; Bash substitutes placeholders with sed and inserts at scaffold:* comments with awk. Generated modules infer Params from SPEC and expose generate(p, ctx) plus ALGO. They use existing AlgoSection -> Section -> createSections and report-shell controls/storage backed by signals/storageSignal. No separate state framework was added.

Existing handwritten pages gain a generated wrapper on first section addition. The wrapper preserves BASE specs/anchors/component. Duplicate inherited section names are checked when the wrapper module loads. Input/copy require scaffolded modules and their markers. Existing typed Algos are reusable with use. Bounds/options/hints and geometry effects are edited in the emitted source; input generation alone does not implement a field's effect on art.

Art modules:
- src/algos/3_guilloche.ts: three harmonic wheels, braided strands, nested bands, ink palettes, four presets; /guilloche.
- src/algos/4_architecture.ts: recursive lancet windows and crown foils.
- src/algos/5_fanvault.ts: corner fans, transverse arcs and central star webs.
- src/algos/6_buttresses.ts: repeated oblique frames and flying arches.
- src/algos/7_spires.ts: main and subsidiary crocketed pinnacles.
- src/algos/8_wheel.ts: radial lancet wheel windows.
- src/algos/9_cloister.ts: perspective arcades and floor joints.
The last six are sections of /architecture, in src/pages/11_architecture.tsx. Shared pointed arch/lancet/spire helpers are in src/lib/2a_architecture.ts. All are added experiments; no further visual revision was performed after rejection.
