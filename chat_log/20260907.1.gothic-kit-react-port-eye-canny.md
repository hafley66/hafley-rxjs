## Key Insights
- Named view timelines are only visible to descendants; `timeline-scope` on body makes header anchors animate on section timelines; keyframes 12%..88% over `entry 0% exit 100%`.
- `var CSS = ...` shadowed the global CSS object and silently killed CSS.supports; rename.
- vite html-proxy 500 = syntax error in an inline module; `node --check` on the extracted script finds it.
- vite-plugin-singlefile refuses multi-entry: one vite.build per entry in a loop works; the built html re-runs any inline redirect, guard on /dist/.
- Chrome blocks module scripts from file://; classic scripts and inline modules work; nav.js is classic so legacy pages get the header from file://.
- Header grid areas (files/ctl, sections, title) keep tab x identical across pages (14,47,87,131 measured).
- Stochastic timing = gaps > 0, cumulative sum normalised: monotone by construction; clamp gaps to silence x median to kill dead air.
- Own-chord slide (theta from the stroke chord, dist in chord lengths) reads as a cut; a global slash angle reads as debris.
- Descartes fourth circle: complex form for centres, pick the root by tangency residual; ring of n equal circles r = R sin(pi/n)/(1+sin(pi/n)).
- FACS mapping: lev = .35 + .8 AU5 (+.15 AU2 -.3 AU4 medial -.15 AU6), aUp up to 1.3; AU6 lifts lower lid .55 and narrows width 6%; AU45 closure with a temporal->nasal zip was the uncanny part.
- Kit contract: static/shuffle:false fields sit in a trailing cluster with no pin; pins travel as `<section>.pin=a,b`; only non-default values print to the URL.
- Never call startViewTransition on first mount (hangs load under playwright).
