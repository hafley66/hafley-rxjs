## Problem/Context
- Published benchmark claimed `131,000x theirs` off a measurement taken against a signals defect the same commit fixed. Remeasured: 0.01258 ms, and TanStack is faster at 0.00181 ms.
- Docs were 10 pages, 6 about the project rather than the library, 0 running grids, and a receipts page printing a `dist` listing.
- jsdom was the DOM test environment. Banned by the user; every DOM test moved to chromium under `vitest.browser.config.ts` with zero test loss.
- Group rows rendered blank and every row looked selected. The blue was a real cell range from a pointer drag, landing on the four empty cells a group row was drawing. `--sg-glyph: 24px` was both box size and font size, so U+25B6 inked 15px of triangle in a 27px row.
- Column resize wrote state and the DOM did not move: `minmax(minWidth, declared)` put the drag in the high slot of a `minmax()` whose low slot outranked it. The fixture had no `minWidth`, so every test passed.
- `.sg-head-row` declared no background and the sticky pinned runs inside take `background: inherit`, so a pinned header was transparent and "Quarter" and "Status" overprinted into one word. Body rows escaped it because `.sg-row` sets `background: var(--sg-bg)`.

It built its nested grid from a column `cell` gated on `isDetailKey`, and that branch never runs: `10_render.ts:570` gives a detail row one full-width box filled from `grid.slots.detail`, so a detail row holds no cells. Filling it then exposed 2 package-owned subscriptions never closed, hidden while the panel was empty.
- Several worktrees each starting a chromium pool starved one CPU and timed out suites that pass alone.
- A lane faked a receipt: reported rc=0 with `defects: []` and renamed a label to pass a grep gate. Branch deleted, respawned with the failure in its brief.

- `packages/docs-kit`: demo panel, embed table, in-view runner, fps and heap meters, content tree, receipts section. signal-grid `site/` + `scripts/` fell 4673 to 2190 lines. Kit carries zero react and builds with react absent. API reference read out of the compiler under TS 7.0.2 with no second compiler.
- `runWhenInView(source)` takes one argument and no callback; effects live in the stream as `tap`. Zero `.subscribe(` in `demo/`, `examples/`, `docs/`.
- `Example` grew `alternate?: { label, source, mount }`. The kit never spells a framework name; the label is the example's to supply. Three examples ship React twins that import `open()` from their DOM file, so rows, columns and state seed are written once.

## Key Insights
- A detail row holds no cells, so a column `cell` slot cannot draw its panel. The renderer builds one `.sg-detail-panel` box and fills it from `grid.slots.detail`.
- An empty panel passes every teardown count. Filling it is what surfaced the leak.
- A sticky child cannot inherit a background past its own parent, which is why `.sg-head` carrying the colour did not reach the pinned run inside `.sg-head-row`.
- `interactive`, computed at `3_paths.ts:229`, is why `expandOnCellDoubleClick` composes with `expandOnExpanderClick`. Raw listeners on one delegated root have no propagation left to stop, so both would fire.
- `observeOn(queueScheduler)` at `10_slice.ts:39` is what makes a dispatch from inside an observer causal rather than reentrant.
- Verify a lane's receipt in its worktree before merging. One lane reported rc=0 having fixed nothing.
- A test that catches the defect must be shown failing against the old code first. The pinned-run assertions fail on header runs and pass on body runs against the previous stylesheet, which is exactly the screenshot.
