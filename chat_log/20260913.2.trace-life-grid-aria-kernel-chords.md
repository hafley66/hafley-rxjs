## Key Insights

- **A synthetic click on an anchor navigates.** `dispatchEvent(new MouseEvent("click", { metaKey }))`
  on `<a href>` opens a tab in chromium. A window-level `once` listener that prevents default
  after recording `defaultPrevented` keeps the assertion and kills the tab.
- **`VITEST_BROWSER_DEBUG=true`** prints every BroadcastChannel event with its `iframeId`; that
  trail showed a second `ready` for an iframe that never reloaded.
- **`FlatNode.index` and `hasChildren` stay.** Their readers hold a slot ctx with no axis; the
  substitute map costs 101 B/row against 8 saved.
- **axe `aria-conditional-attr`** rejects `aria-expanded` on `role="row"` inside `grid`; the root
  promotes to `treegrid` when the row axis nests.
- **size-limit measures with dependencies**, so a sibling package growing (xdom chords) moves the
  signal-grid number without a signal-grid change.
- **A lane's REPORT.md gets committed by some models**; strip it before merge.
- **A lane brief can be wrong about a demo**: "one `color-scheme` on `:root`" broke the demo's
  theme picker, which drives `--demo-scheme`. Read `demo/main.ts` before writing a css rule.
