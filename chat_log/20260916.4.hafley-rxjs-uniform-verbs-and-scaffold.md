## Problem/Context
- `@size-limit/time` measures each matched file in parallel with three runs each → one Chrome per file, outside the machine-wide queue; `dist/*.js` matched 3 files in the bundle shape and 21 in a preserved-module experiment (63 Chromes per run), which is the storm another lane measured as 264 processes.
- `resource$` reports an `open()` rejection and never reaches its close half, so `serve: {kind:"command"}` spawned detached in its own process group outlived the run; `acquireSlot` polled with no deadline, so one live-but-stuck holder parked a worker (and the machine-wide queue lock) forever.
- `newest()` returns 0 for a path that does not exist and the `reuseExisting` base was hard-coded `<root>/src`; fixture roots keep sources beside `index.html`, so `newest(dist) >= 0` was always true → a stale fixture build would have been reused silently forever.
- `docs/MONOREPO.md` already documented the four verbs; 21 of 37 manifests had drifted (11 wrote `-p tsconfig.json`, 6 skipped `pnpm run`, 3 kept a `lint`, 2 had no `receipts`).
- Changesets: `linked` groups `grapht-model/grapht/mmd/d2`; `privatePackages {version:false,tag:false}`; everything else versions independently (8 distinct versions, 7 changesets pending).
- Root `pnpm lint` was aborting on `.boop-worktrees/*/biome.json` (nested root config) because `vcs.useIgnoreFile` was false; it now reports instead, and what it reports is 964 errors / 355 warnings over 850 files.

## Solution/Approach
- Resource fixes: byte gates keep working, browser measurement dropped; the serve child is SIGTERM'd on its process group (SIGKILL after 5 s) inside the failing `open()`; slot waits fail after `semaphore.timeoutMs` (10 min default).
- `reuseExisting` base is `<root>/src` when it exists, the root otherwise; `newest` already skips `dist` and `node_modules`.
- Shape as data + assertion: `scripts/audit-packages.mjs` gained `shapeProblems()` and a "Uniform script shape" section, exiting 1 on any finding. Rules: four verbs present (build except the two artifact-free private packages), `typecheck` starts `tsc --noEmit`, `receipts` starts `pnpm run typecheck` and contains a test step, no `lint` in a package or its gate, every step spelled `pnpm run`, `check` == `pnpm run receipts`. Step order otherwise left alone (five packages' `test` reads their own build output).
- Scaffold is one bash script with two commands; templates hold tokens only, every input is read at run time from the manifest that owns it (`scaffold.*`, root devDependencies, `engines.node`, `packageManager`, `biome.json` `$schema`); unknown token → the run fails and names itself; staging dir + `mv`; never overwrites; no `pnpm install`.

## Key Insights
- The four-verb contract was already the repo's documented intent; the work was making it assertable (`exit 1`) rather than descriptive, and the residue is the runner/builder spread that uniformity must not paper over.
- A skeleton that is only *text* rots; the scaffolder reads live manifests for every version it writes, and biome's version must be exact because biome refuses a config whose `$schema` it does not match (a caret resolved to 2.5.13 against a 2.3.11 schema and the new repo's lint failed before running).
- Template tokens can be unstable under substitution: `{ type __Ident__Options, defaults }` re-sorts once the placeholder becomes a real name, so the template avoids mixing type and value specifiers (`export * from`, value-only test import).
- Chrome-launching gates belong in `scripts/browser-queue.mjs` or must not launch Chrome; 18 entry points are queued, 23 are not (benches, labs, playwright configs).
