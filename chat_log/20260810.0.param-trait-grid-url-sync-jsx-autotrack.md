## Problem/Context
- "make route params composable": a typed value (RHS codec) mounts on a route
  key (LHS). `Param<T>` = `{parse(raw): T|undefined; print(value:T): string}`.
  Same codec reused under different keys on different routes. devalue over whole
  GridState is the ASSUMED serializer (never declared by the caller).
- React binding reality (corrected mid-session): there is NO `use$` export and
  NO `.use()` on the signal accessor (the `0_types.ts:29` doc comment is
  aspirational). Real API in `signals/src/3_react.ts`: `SignalReact(Component)`
  (observer wrapper, auto-tracks `.$()` reads during render) and
  `useSignal(signal$)` (hook). `useGrid` (grid `3_react.ts`) wraps `useSignal`.
- Grid export split: main `@hafley66/grid` exports createGrid/gridStateParam/
  Grid type; `@hafley66/grid/react` exports GridTree/GridTable/useGrid.
- `createGrid<FSNode>` needs the explicit type arg when the zod schema omits
  optional fields (children) so `getSubRows: n => n.children` typechecks.

## Solution/Approach
### Done
- Param trait: mount one Param per name via `{params}`, compose into typed
  Values. One blob per key (devalue). Route-local key per page; same gridStateParam
  reused everywhere.
- Grid sync: `sync:{key}` is the whole switch. `state?` stays as custom-signal
  escape hatch. Persist is a `tap`/internal sub, never naked `.subscribe` at the
  call site (hard rule from prior session, honored).
- Cross-route reuse: `const gridFor = (key) => createGrid({...sync:{key}})`.

### PENDING — vite-plugin JSX auto-tracking (the next build)
User wants every React component to auto-track signal reads during render,
globally, WITHOUT a per-component `SignalReact` wrap. The reconciler itself is
NOT the hook point (React 19 doesn't expose per-render hooks). Lever = the JSX
runtime. With the automatic runtime, JSX compiles to `react/jsx-runtime.jsx`,
NOT `React.createElement`.
**Plan**: a vite plugin that sets `jsxImportSource` to a custom runtime shipped
by signals; that runtime re-exports `react/jsx-runtime` but wraps every
function-component `type` in `SignalReact(type)` (cached by WeakMap). This
globalizes the existing `memoWrap` tracker (`signals/src/3_react.ts:28`).
The operator (already in memoWrap, per fiber instance):
```
start.next() -> component() reads A.$(),B.$() -> end.next()
combineLatest([A,B]).subscribe(forceUpdate)   // takeUntil(next render)
A changes -> forceUpdate -> React re-renders -> switchMap cancels, re-collects
```
switchMap = each render re-derives deps; takeUntil(end) = per-render scope;
the fiber instance (useMemo(memoWrap,[])) is the "outerRenderIdHashKeyThingy".
Constraints: function components only (class/forwardRef/memo need unwrap);
jsx-runtime patch (not createElement); build-grade = vite jsxImportSource alias
(not runtime monkey-patch of react/jsx-runtime exports).

## Key Insights
- Reconciler is not patchable without a fork; the JSX runtime (react/jsx-runtime)
  is the hook point for React 19 automatic runtime.
- The existing memoWrap/SignalReact already does switchMap+combineLatest+takeUntil
  per fiber; the vite plugin just applies it to every function component.
- `signalDispatch` (1_SignalCreator) emits `{type:"get"}` on each `.$()` read;
  memoWrap filters those during a render window. This is the collection mechanism.
- One unbuilt dist cascades phantom type errors; rebuild path+signals before
  debugging grid types.
