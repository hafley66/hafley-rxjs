## Key Insights
- `vector-effect: non-scaling-stroke` breaks every `pathLength=1` dash trick; scope it to unit-coordinate generators only.
- CSS rules beat SVG presentation attributes; set per-path widths as inline `style` when a global path rule exists.
- A sticky `<details>` drawer works when a ResizeObserver writes its height to `--kit-drawer` and section titles use `top: calc(var(--kit-top) + var(--kit-drawer))`; folded 29px / open 372px on slice.
- React portals into a container rendered by the parent: read the container in an effect (`useState` + `getElementById`) so children mount in section order after the body exists.
- In-process Agent subagents survive `/clear`; ListAgents shows them.
- Old and new slice timing were identical (finished seal holds the last 350 ms of a 1370 ms cycle); side-by-side worktree (`git worktree add --detach` + symlinked node_modules) was the decisive check.
- gothic `describe(key, fd)` builds tooltip text: hint, then `key: kind window · default · shuffle rule`; the row's `title` covers every control; smoke asserts it.
- Store semantics: `save(name)` creates or overwrites by name and selects; while selected, every edit writes into that state and the autosave.
