## Solution/Approach
Measured, not guessed (all numbers from real renders):
- d2 never wraps markdown prose; `width:` on a markdown shape is ignored (asked
  300, got 579). 331-char paragraph renders as one 2085-wide line.
- Board ladder: today 25347x4431 | elk 25511x2741 | rewrap source 25354 (markdown
  rejoins lines) | hard <br/> breaks at 40 cols 12020x6032 | + auto grid-columns
  round(sqrt(children)*2) 5133x6358.
- Full relayout after adding one node to one group: 10 of 10 unrelated nodes
  moved, worst drift 131 units. That is why collapse needs projection not relayout.
Buy-vs-build verdict (two research agents, real npm data):
- layout solver: BUY, already owned (cytoscape 3.34 + fcose 2.2, ranked #1 of 7
  for compound groups + constraint-based stability; elkjs #2 but 433KB and no
  incremental; d3-dag and graphology have no compound support at all)
- wrap/grid policy: build, small, zero deps
- collapse projection: build (no product sells it; cytoscape.js-expand-collapse
  abandoned) -- BUT VERIFY AGAINST EXISTING CODE FIRST
- headless box engine (Yoga/Taffy/browser CSS): neither. Yoga has no CSS Grid,
  Taffy has no first-party JS build, and React Flow/Svelte Flow/Mermaid all
  measure with DOM then place with dagre/ELK. Nobody uses CSS for node placement.

## Key Insights
- d2 arch board is ingested as ONE sealed SVG node: zero d2 meta. Only sequence
  diagrams have a real parser (packages/d2/src/1_parse.ts) and bindings.
- tspan `y` is an absolute override; setting it discarded the text baseline and
  piled all 35 node bodies at the top of the diagram. Fixed by dropping tspan y.
- VitePress intercepts same-origin clicks and paints its own 404; strip tabs need
  target="_top" to force a real cross-site navigation.
- The renderer captures the pointer on pointerdown, which retargets clicks away
  from any chrome inside the host. Guard chrome selectors in onPointerDown.
- StorageSignal nested writes work correctly (tested in chromium); the library was
  never at fault this session.
- Lanes finished work twice but never committed (rc=4, 0 commits). Salvage by
  committing from the worktree, then merge.
- Epic is small: 164 declarations, 46 containers, 46 edges, max nesting 3. Perf
  arguments about thousands of boxes do not apply.
