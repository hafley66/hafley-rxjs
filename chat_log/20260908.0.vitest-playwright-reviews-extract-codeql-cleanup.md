## Key Insights
- AsyncLocalStorage does not survive playwright's event dispatch; a "sole active attempt" fallback is the correct shape for `$page` inside handlers, with an explicit error under concurrency.
- Capture timers at module import; any `vi.useFakeTimers` after that cannot reach them. The playwright client itself cannot be protected, only teardown can.
- vitest keeps one AbortController per test across retries; derive a per-attempt signal.
- `Signal(observable)` is refCount-lazy; the test harness boundary is the one sanctioned subscriber.
- extract's unique wins are structural (span containment, inferred types, zero-ref sets); it cannot read node_modules or runtime. CodeQL's edge on this package was two relations: exception-aware CFG and ancestor containment, both AST-lowered. SCIP stays for resolution; the gaps go into extract as fact families, not QL.
- Never import `vitest/config` or `vitest/node` types from a package that augments `Assertion`.
