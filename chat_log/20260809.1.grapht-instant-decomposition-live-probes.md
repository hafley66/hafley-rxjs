## Solution/Approach
- Keep the durable model, parser output, geometry, diffs, event journal, and projection inputs framework-free.
- Permit React adapters for the first Instant/Cytoscape/XYFlow integration.
- Use immutable artifact revisions and entity graphs, content-addressed render caches, separate placement journals, and keyed entity diffs.
- Use `@hafley66/grid` for all network/session/trace row views. Graph, waterfall, sequence, and marble projections consume the same selected row set and entity IDs.
- Extract Instant Markdown parsing, sections, source spans, links, embedded diagrams, and document state into grapht. Instant retains filesystem access, Dockview registration, native open/reveal, host preferences, and application styling.
- Record library dependencies and capability surfaces for network/graph geometry without qualitative build-versus-buy statements.

### Camera-aware section labels, TOC, and editable code blocks

- Large D2 and SVG documents need an organizational annotation layer driven by graph geometry
  and camera state.
- D2 classes or metadata mark section titles separately from ordinary node labels.
- Section-title typography remains constant in screen pixels instead of scaling with world
  geometry.
- A visible title position is clamped to the intersection of its section bounds and the camera
  viewport, so the title remains associated with its section while that section is visible.
- Section identities also feed a compact FigJam-style layer/section TOC for orientation and
  camera navigation.
- D2 remains the authored structural source. Camera-aware title placement is a view projection,
  so the renderer does not rewrite source coordinates while panning or zooming.
- Code blocks retain artifact, revision, language, and source-span identity. Monaco can provide
  an editable code surface while D2, SVG, Canvas, and graph views display projections of the
  same source-backed block.
- Code edits create new artifact revisions and enter the existing parse, render, geometry,
  and diff pipeline.
- Added the `CameraState`, `SectionAnnotation`, `AnnotationPlacement`, `AnnotationProjector`,
  and `EditableCodeBlock` contracts to `packages/grapht/1_app_model.d2`.
- Large sequence diagrams use the same annotation projection. Participant headers retain a
  constant screen-space font size and stick to the visible edge of their participant columns.
- Sequence phase or section labels stick within the visible portion of their time intervals.
  Horizontal and vertical navigation therefore retain the active participants and phase as
  viewport-local context.
- Sticky sequence annotations are derived from participant, phase, column, and time-interval
  identities. They do not mutate authored sequence coordinates or SVG nodes during camera
  movement.
- Added `SequenceCameraContext` and `SequenceAnnotationProjector` contracts to the grapht model.
