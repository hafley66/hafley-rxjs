## Solution/Approach
- signalMap: pipe operator reusing the module-private `dependencyCollectors` stack via exported `trackDependencies(compute, sink)`; `running`+`dirty` guards (memo re-entrancy parity); BehaviorSubject self-emit-on-subscribe blocked by `initializing` flag.
- route: route-local template-literal parser (RouteSegment/RoutePathOutput) infers scalar types from `{scalar:name}`; normalizes to `{name}` for the existing string-based IPath; zod coercion at the route layer. Boolean via `z.union([z.boolean(), z.literal("true"), z.literal("false")]).transform()` (z.coerce.boolean is broken: "false"→true).
- signalHistory: state-machine — location/action are Signals whose observable def is the switchMap; `Signal(obs, default)` scopes the subscription tree; user mandate was "let rxjs sub tree do its job" + "use signal(observable) not shareReplay({refCount})".
- sync: generic bidirectional binder; one-line seam reused for any two signals.
- grid features: generic `on(key): OnChangeFn<GridState[K]>` writes the slice (whole-state read/write `state.$({...state.$(), [key]: value})`) + emits `{type: key, [key]: value}` event.
- browser render: `GridTable` convention — column id `"__expand"` renders the arrow (row.getCanExpand() ? ▶ : none), column id `"name"` indents by `row.depth * 18`.
