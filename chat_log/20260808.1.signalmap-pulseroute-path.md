## Problem/Context
- signalMap = pipe operator: projects source emissions against tracked signal values, re-emits on any read signal change. Stay-open (BehaviorSubject dominates, never completes with source). Home: packages/signals (rxjs-ext is passthrough rxjs). Built on the module-private `dependencyCollectors` stack (`1_SignalCreator.ts`).
- pulse-route discovery: the existing path library (`0_types.ts`, `1_path.ts`) ALREADY implements `print`/`match`/`concatenate`/`ValuesOf`/`PathConversion`. The route is a zod adapter + typed-template extension, NOT a new matcher. The plan's 3-arg API predates reading the library.
- Typed-template lab requires extending CORE machinery: `SegmentValues` (`0_types.ts:37`), `PartOfSegment` (`0_types.ts:86`), `partOf` regex + `rawMatch` coercion (`1_path.ts:67,155`) to recognize a new `{scalar:name}` segment form alongside existing `{name}`/`{name?}`/`{name*}`/`:name`.
- Comment-prod hook enforces max 2 consecutive comment lines, constraint-only. JSDoc blocks count.

## Solution/Approach (signalMap — DONE)
- `trackDependencies<T>(compute, sink)`: pushes a collector onto `dependencyCollectors`, runs compute, pops in finally. `sink` keeps deps observed before a throw (recovery parity with `createComputedSignal`).
- `signalMap<I,O>(project): OperatorFunction`: `new Observable`; on `source.next` stores `{value:I}`, calls `recompute`. `recompute` guarded by `running`+`dirty` flags (re-entrancy parity with memo). `run()`: `trackDependencies` collects deps, resubscribes via `subscribeDep` (`initializing` flag blocks BehaviorSubject's synchronous self-emit), on error keeps `lastOutput` + resubscribes partial deps. No `complete` handler — output stays open.

## Solution/Approach (pulse-route — DESIGNED, not built)
- Extend `SegmentValues`/`PartOfSegment` (`0_types.ts`) to map `{number:Name}`→{Name:number}, `{string:Name}`→{Name:string}, `{boolean:Name}`→{Name:boolean}, fallback `{Name}`→string.
- Extend `partOf` regex (`1_path.ts:67`) + `rawMatch` coercion (`1_path.ts:155`) for typed params; `printPath` must String() scalars.
- Add `zod ^4.4.3` dep to packages/path (plain version, not `workspace:`; lockfile already carries zod 3.x and 4.x).
- New file `packages/path/src/2_route.ts`: `route(template, querySchema, payloadSchema)` + `NumberPathParam`/`StringPathParam`/`BooleanPathParam` helpers. Returns `{ path, schema, href, match }`. No `$`.
- Consumer-breakage risk: `packages/path-router-lab/src/6_IPath.target.oracle.ts` heavily relies on segment forms (the type-level oracle). Render regexes (`toReactRouterPattern`/`toTanStackPattern`/`toOpenApiPattern` at `1_path.ts:300,307,314`) use char classes that allow colons — may mis-parse `{scalar:name}`, needs checking. grid (`1_types.ts`) uses only `ObjectPathsOf` — safe.
