## Key Insights
- A disc touching the apex point of a pointed arch can never sit inside the wedge; the apex foil must be inscribed tangent to both arcs (centre on axis at distance r-rho from both arc centres).
- Cusp = the intersection of adjacent lobe discs farther from the centroid of centres (union boundary), not the inward one.
- Lobe radius must be found by bisection twice: smallest radius where neighbours still meet, then largest radius whose 16 sampled disc points stay inside the region; if fit < meet, fall back to plain and caption it.
- `<use>` clones lose stylesheet fill:none; set presentation attributes on the group.
- CSS `fill: none` on paths overrides the `fill` attribute; pattern fills need inline style.
- Hankin rays are collinear at square 45 / hex 30; join midpoints directly.
- Dense CSS grid: `repeat(auto-fill, 40px)` + `grid-auto-rows` + `grid-auto-flow: dense` with per-cell column/row spans from the svg px size packs mixed sizes; min span 2 keeps captions readable.
- pushState with a query works on file:// in Chromium; keep a `#?` fallback.
- Asymmetry by replaying recorded rng draws blended with fresh draws keeps the right side stable under the slider.
- zod field abstraction: schema derived from input type; per-key safeParse so junk URL keys drop silently.
